# Эйра в All Hub: быстрый запуск (Android и Windows)

## Ollama — локальный чат
1. Установите Ollama на компьютер и скачайте совместимую с его памятью модель командой `ollama pull <имя-модели>`.
2. Запустите Ollama. В All Hub откройте **ИИ → локальный чат Эйры**.
3. На Windows при запуске Ollama на том же ПК используйте `http://127.0.0.1:11434`. На Android `127.0.0.1` означает **телефон**, а не ПК: понадобится адрес ПК в локальной сети и разрешённый доступ к Ollama.
4. Нажмите проверку подключения, выберите обнаруженную модель и отправьте тестовое сообщение. Без модели ответы не появятся.
5. Характер и память настраиваются отдельно от модели. Экспорт памяти создаёт локальный JSON, который можно импортировать на другом устройстве. **Автоматической синхронизации между устройствами пока нет.** История чата и память — разные хранилища.
6. При удалённом Ollama передача личного контекста выключена по умолчанию: разрешайте её только для доверенного сервера. Не открывайте порт Ollama в интернет.

## Forge — генерация и сохранение
1. На компьютере запустите Stable Diffusion WebUI Forge с `--api`, предварительно установив совместимую модель.
2. Откройте **ИИ → Forge**, укажите `http://127.0.0.1:7860` на том же ПК либо LAN-адрес ПК на Android. Не выставляйте Forge API в публичный интернет.
3. Нажмите **Проверить подключение и модели**. Успешное обнаружение списка моделей не гарантирует, что выбранная модель поместится в видеопамять.
4. Введите промпт, при необходимости отрицательный промпт, установите шаги и разрешение. Для слабых видеокарт начните с **512 × 512**.
5. Нажмите **Создать изображение**. После ответа Forge изображение показывается в приложении, **не записываясь автоматически**.
6. Нажмите **Сохранить PNG/JPEG** и выберите место через системный диалог. Отмена сохранения оставляет изображение только в текущем экране. При ошибке сети, недостатке видеопамяти или повреждённом ответе приложение показывает ошибку.

## Ограничения
- API Ollama и Forge работают на устройстве или доверенном LAN-сервере, не в облаке All Hub.
- Для подключения Android к ПК необходима доступность ПК по сети и соответствующие настройки брандмауэра.
- Не отправляйте в публичный GitHub личные переписки, экспорт памяти, ключи или приватные изображения.
- Проверка CI подтверждает компиляцию и автоматические тесты, но не заменяет испытания на реальном Android и Windows.
- Codex и GGUF — отдельные инструменты во вкладке ИИ; поддержка GGUF зависит от платформы и нативного движка.
